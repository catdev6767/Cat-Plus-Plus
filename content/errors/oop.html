Lỗi OOP

17. Tạo instance của abstract class

cat abstract Shape
    purr area()
Shape()

Lỗi: Khong the tao instance cua abstract class 'Shape'

Sửa: Tạo class con kế thừa và override method abstract.

18. Method không tồn tại

cat Point
    paw x
    paw y
paw p = Point(1, 2)
meow p.area()

Lỗi: Instance khong co 'area'

Sửa: Thêm method area vào class.

19. Class con chưa override abstract

cat abstract Shape
    purr area()
cat Circle kin Shape
    paw r
Circle(2)

Lỗi: Class 'Circle' chua override 'area'

Sửa: Thêm purr area() trong class con.

20. Thuộc tính không tồn tại

cat Point
    paw x
paw p = Point(1)
meow p.y

Lỗi: Instance khong co 'y'

Sửa: Khai báo paw y trong class.
