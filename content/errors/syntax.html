Syntax error

1. Incorrect Indentation

purr test()
meow "hi"

Error: Can 'NEWLINE', gap 'MEOW'

Edit

purr test()
    meow "hi"

2. Mix tabs and space

purr test()
\tmeow "hi"    # tab
    meow "yo"  # space

EditUse space only. 4 spaces per level.

3. Missing brackets

paw x = (5 + 3

Error: Can ')', gap 'NEWLINE'

Edit paw x = (5 + 3)

4. Use the keyword as a name variable

paw meow = "hi"

Error: Not parse is — meowis the keyword.

Edit paw greeting = "hi"

5. Forgetting to print a colon in struct

struct Point
    x i32
    y i32

Error: Can ':', gap 'IDENT'

Edit

struct Point
    x: i32
    y: i32

6. String not closed

meow "hello

Error: Unterminated string

Edit meow "hello"

7. Use=instead==

sniff x = 5
    meow "yes"

Error:Parse to assign, not compare.

Edit sniff x == 5

8. Excess semicolon

paw x = 5;
meow x;

Error:Cat++ don't use;as C.

EditJust dump it.;.
