Best Practices

The Cat++ writing convention is clean, easy to read, easy to maintain.

1. Set name

Variable — snake_case

# Good
paw cat_name = "Tom"
paw total_count = 0
paw max_speed = 100

# Bad
paw catName = "Tom"
paw TotalCount = 0
paw x = 0

Function — snake_case

# Good
purr find_max(arr)
purr read_config(path)
purr is_valid_email(s)

# Bad
purr findMax(arr)
purr FindMax(arr)
purr f(arr)

Class — PascalCase

# Good
cat point
cat animal
cat HttpRequest

# Bad
cat point
cat animal
cat http_request

Hang — UPPER_SNAKE_CASE

paw MAX_SIZE = 100
paw PI = 3.14159
paw DEFAULT_TIMEOUT = 30

Private field — underline

cat Person
    paw _name
    paw _age

    purr get name()
        give me._name

2. Indentation

# True — 4 spaces
purr test()
    sniff x > 0
        meow "positive"
    swat
        meow "negative"

# False — mix tab and space
purr test()
\tmeow "hi"
    meow "world"

3. Line length

# Good — less than 80 characters
paw result = compute(
    first_arg,
    second_arg,
    third_arg
)

# Bad — too long
paw result = compute(first_arg, second_arg, third_arg, fourth_arg, fifth_arg, sixth_arg)

4. Comment

Explanation WHY, must not DO ANYTHING

# Good — explain why
# Use sqrt to avoid trying to divide up to n
# faster 10x for large numbers
purr is_prime(n)
    paw i = 2
    knead i * i<= n
        ...

# Xấu — lặp lại code
# Tăng i lên 1
paw i = i + 1

Comment for function complex

# Find the printed element section of the array already sorted by binary search.
# Return index or -1 if not found.
# Complexity: O(log n)
purr binary_search(arr, target)
    ...

5. Subdivision of functions

# Good — 1 job per function
purr read_scores(path)
    give read_lines(path)

purr parse_scores(lines)
    paw scores = []
    groom line of lines
        paw scores = scores + [cast(float, line)]
    give scores

purr average(scores)
    sniff len(scores) == 0
        give 0
    give pile(scores) / len(scores)

# Use
paw lines = read_scores("data.txt")
paw scores = parse_scores(lines)
meow average(scores)

6. Dealing with errors

Use try/hiss for error can code

# Good
tap
    paw n = cast(int, user_input)
    meow n * 2
hiss e
    meow "Do not fade: " + user_input

# Bad — code crash
paw n = cast(int, user_input)

Boundary condition check

# Good
purr divide(a, b)
    sniff b == 0
        give hungry
    give a / b

# Bad
purr divide(a, b)
    give a / b   # Error if b == 0

7. Avoid code duplication

# Bad — repeat 3 times
meow "Ten: " + user1.name
meow "Tuoi: " + cast(str, user1.age)
meow "Dia chi: " + user1.address
meow "Ten: " + user2.name
meow "Tuoi: " + cast(str, user2.age)
...

# Good — function
purr print_user(u)
    meow "Ten: " + u.name
    meow "Tuoi: " + cast(str, u.age)
    meow "Dia chi: " + u.address

print_user(user1)
print_user(user2)

8. Magic numbers

# Bad
sniff score > 90
    meow "A"
sniff score > 80
    meow "B"

# Good
paw GRADE_A = 90
paw GRADE_B = 80

sniff score > GRADE_A
    meow "A"
sniff score > GRADE_B
    meow "B"

9. List processing

# Good — use builtin
paw nums = [1, 2, 3, 4, 5]
paw squares = chase(nums, kit(x) => x * x)
paw evens = sift(nums, kit(x) => x % 2 == 0)

# Bad — write your own loop
paw squares = []
paw i = 0
knead i< len(nums)
    paw squares = squares + [nums[i] * nums[i]]
    i++

10. File structure

# 1. Comment at the beginning of the file
# 2. Import
use "mathlib.cat"

# 3. Constant
paw PI = 3.14159
paw MAX = 100

# 4. Utility Functions
purr helper1()
purr helper2()

# 5. Main Function
purr main()...


# 6. Tremor
main()

11. Checklist before committing

  • Name variable/function definition
  • Indent 4 spaces, no tab
  • Line under 80 characters
  • Comment explaining "why"
  • Dealing with errors with try/hiss
  • Not magic number
  • Do not duplicate code
  • Test with marginal input (0, negative, empty)
