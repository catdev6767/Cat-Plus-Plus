Felis OS — A Complete Guide

From Cat++ code to kernel boot on bare metal, no Linux, no Python.

1. Overview of architecture

Folder Structure

~/catpp/
├── tools/
│   └── transpiler.py              # Cat++ → C Translator
│
├── runtime/
│   ├── catpp_rt.h                 # shared header (hosted + freestanding)
│   └── catpp_freestanding.c       # VGA, serial, memory for kernel
│
├── kernel/
│   ├── main.c                     # Kernel entry (kmain)
│   ├── entry.s                    # Assembly boot (_start)
│   ├── linker.ld                  # Linker script
│   └── demo.cat                   # Code Cat++ demo
│
├── libc/

3. Syntax low-level is only available in Felis OS

Bit operations

paw a = 0xFF & 0x0F       # AND → 15
paw b = 5 | 2             # OR → 7
paw c = 5 ^ 3             # XOR → 6
paw d = ~0                # NOT → -1
paw e = 1 << 4            # SHL → 16
paw f = 256 >> 4          # SHR → 16

Cast to pointer

paw vga = cast(ptr, 0xB8000)
# VGA address text mode. 80x25 characters, 2 bytes each:
# bytes 1 = characters, bytes 2 = colors

Struct C-layout

struct Color
    r: u8
    g: u8
    b: u8
    a: u8

paw red = Color(255, 0, 0, 255)
meow sizeof(Color)   # 8

Volatile for MMIO

volatile paw status = 0
# Compiler will not optimize this variable

Inline assembly

asm("cli")   # Disable interrupt
asm("sti")   # Enable interruptions
asm("hlt")   # Stop CPU
asm("nop")   # What not to do

4. Write kernel code

Examples 1: Print "Hello"

meow "Hello from Felis OS!"

Examples 2: Loop

paw i = 0
knead i < 10
    meow i
    i++

Examples 3: Function

purr fib(n)
    sniff n <= 1
        give n
    give fib(n - 1) + fib(n - 2)

meow fib(10)

5. Build script

bash build_felis.sh

Build steps:

  1. Transpile demo.cat → demo.c
  2. Compile entry.s → entry.o (assembly)
  3. Compile runtime → rt.o (VGA, serial)
  4. Compile main.c → main.o
  5. Compile demo.c → demo.o
  6. Linkall. felis.elf

6. Run on QEMU

Option 1 — Terminal (windowless)

qemu-system-x86_64 \
    -kernel kernel/felis.elf \
    -m 128M \
    -display none \
    -serial stdio

Option 2 — Graphic window

qemu-system-x86_64 -kernel kernel/felis.elf -m 128M

Option 3 — Create bootable ISO

# Need grub2-tools
mkdir -p iso/boot/grub
cp kernel/felis.elf iso/boot/
cat > iso/boot/grub/grub.cfg<< 'GRUB'
menuentry "Felis OS" {
    multiboot /boot/felis.elf
    boot
}
GRUB
grub2-mkrescue -o felis.iso iso
qemu-system-x86_64 -cdrom felis.iso

7. Runtime freestanding

VGA text mode

VGA buffer at address0xB8000. 80 columns × 25 rows. 2 bytes per character:

  • Byte 0: ASCII character
  • Byte 1: color (4 bits background + 4 bits text)

Color Scheme:

0 = black      4 = deep red 8 = dark gray 12 = light red
1 = dark blue 5 = dark purple 9 = light blue  13 = pink
2 = dark green 6 = brown        10 = light green 14 = andng
3 = dark blue 7 = light gray   11 = light blue    15 = white

Serial port (COM1)

Write out the gate0x3F8. QEMU with -serial stdiowill appear in the terminal. Used to debug the kernel.

Memory

Bump allocator: linear allocator from0x100000 (1MB) to 0x400000(4MB). Not yet availablefreereal

8. Current Limits

  • None keyboard input
  • None filesystem
  • None process
  • None heap allocator
  • Only 1 CPU
  • 64-bit not supported
  • Subset Cat++: meow, paw, sniff, knead, purr, give, struct, cast

Step 1 — Keyboard driver

Read from port 0x60∙ Set IRQ1. Translate scancode to ASCII.

Step 2 — Timer interrupt

Set pit (Programmable Interval Timer) at 100 Hz. Use for scheduler.

Step 3 — Heap allocator

Replace bump allocator with free list. Need to manage blocks.

Step 4 — Shell

Prompt cat> + read from keyboard + parse + run Cat++.

Step 5 — Filesystem

Set FAT16 or FAT32. Need driver to read/write sector from disk.

11. Examples: drawing letters on VGA

struct VgaChar
    ch: u8
    color: u8

paw VGA = cast(ptr, 0xB8000)

purr putc(row, col, ch, color)
    paw index = row * 80 + col
    # *(VGA + index*2) = ch | (color << 8)

putc(0, 0, 72, 0x0F)    # 'H' trắng trên đen
putc(0, 1, 101, 0x0F)   # 'e'
putc(0, 2, 108, 0x0F)   # 'l'
putc(0, 3, 108, 0x0F)   # 'l'
putc(0, 4, 111, 0x0F)   # 'o'
