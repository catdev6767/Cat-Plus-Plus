Hiểu sâu về interpreter: từ source code đến output.

2. Lexer

Đọc từng ký tự, tạo token. Xử lý:

  • Số: 42, 3.14, 0xFF, 0b1010
  • Chuỗi: "hello" với escape \n \t \"
  • Identifiers: foo, bar_baz
  • Từ khóa: meow, paw, purr
  • Toán tử: + - * / % == != & | << >>
  • Layout: INDENT, DEDENT, NEWLINE

Ví dụ

paw x = 42

Tokenize thành:

PAW("paw")  IDENT("x")  ASSIGN("=")  NUMBER(42)  NEWLINE

3. Parser

Nhận tokens, tạo AST (Abstract Syntax Tree). Dùng recursive descent — mỗi hàm parse một loại cấu trúc.

Precedence chain (từ thấp đến cao)

expr
 ├── or_          (or, either)
 ├── and_         (and, with)
 ├── not_         (not, never)
 ├── in_          (in)
 ├── bit_or       (|)
 ├── bit_xor      (^)
 ├── bit_and      (&)
 ├── shift        (<<, >>)
 ├── cmp          (==, !=, <, >, <=, >=)
 ├── add          (+, -)
 ├── mul          (*, /, %)
 ├── unary        (-, ~)
 └── postfix      (call, index, dot)

Ví dụ AST

paw x = 1 + 2 * 3

Parse thành:

('let', 'x',
  ('+', ('num', 1),
        ('*', ('num', 2), ('num', 3))))

Vì * có độ ưu tiên cao hơn +, nên 2*3 được nhóm trước.

4. Interpreter

Duyệt AST. Mỗi node có hàm eval_() (biểu thức) hoặc exec_() (câu lệnh).

Environment (scope)

class Env:
    vars: dict          # biến trong scope này
    parent: Env         # scope cha

Khi tìm biến `x`:
1. Nếu x trong vars → trả về
2. Nếu không → tìm trong parent (đệ quy)
3. Nếu không có → lỗi

Ví dụ scope

paw x = 10          # global

purr f()
    paw y = 20      # local
    meow x          # đọc được x (global)
    meow y          # đọc được y (local)

f()                 # OK
meow y              # LỖI — y chỉ tồn tại trong f

6. Exceptions

Dùng Python exception để điều khiển luồng:

  • ReturnEx — thoát hàm trả về giá trị
  • StopEx — thoát vòng lặp (sit)
  • SkipEx — bỏ qua lần lặp (leap)
  • CatError — lỗi runtime (chia 0, biến chưa khai báo)
# Khi gặp `give x`:
raise ReturnEx(value)

# Trong hàm:
try:
    for stmt in body: exec_(stmt)
except ReturnEx as e:
    return e.v

7. Module system

3 file:

  • core/registry.py — đăng ký API giữa modules
  • core/bus.py — event bus
  • core/loader.py — auto-load modules

Interpreter đăng ký với registry:

class InterpreterModule(BaseModule):
    def setup(self):
        self.registry.set('interpreter', self)

    def run(self, code):
        return run_catpp(code)

Module khác gọi qua registry:

interp = self.registry.get('interpreter')
result = interp.run("meow \"hi\"")

9. Transpiler Cat++ → C

Khác với interpreter. Không thực thi AST mà sinh C code.

# Cat++ AST
('let', 'x', ('+', ('num', 1), ('num', 2)))

# C code sinh ra
long x = (1 + 2);

Dùng 2-pass:

  1. Pass 1: scan struct, infer return types
  2. Pass 2: generate C code

10. Giới hạn hiệu năng

Interpreter tree-walking chậm hơn C khoảng 100x. Lý do:

  • Mỗi biểu thức duyệt AST (function call overhead)
  • Type động (kiểm tra kiểu runtime)
  • Python VM (chậm hơn native)
  • Không có JIT

Muốn nhanh hơn:

  • Compile sang bytecode (nhanh 5-10x)
  • Transpile C (nhanh gần bằng C)
  • JIT với LLVM (nhanh bằng C)
