4. Recursion Restrictions

# Bad — slow recursion

    sniff n<= 1
        give n
    give fib(n - 1) + fib(n - 2)

meow fib(30)   # ~2 giây
# Good — loop

    sniff n<= 1
        give n
    paw a = 0
    paw b = 1
    paw i = 2
    knead i <= n
        paw c = a + b
        paw a = b
        paw b = c

Memoization

purr fib(n)
    sniff n <= 1
        give n
    sniff seek(memo, n)

    paw r = fib(n - 1) + fib(n - 2)

5. Avoid creating redundant objects

6. Use the bit operator when can

# Good (only with positive integers)

10. Conclusion

Cat++ not allowed to design for performance. If you need to quickly:

  1. Use builtin instead of writing your own
  2. Avoid deep recursion
  3. Cache value in loop
  4. If still slow → transpile to C
