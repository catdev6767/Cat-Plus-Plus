Expression evaluation

Left to right, respecting precedence:

  1. ()
  2. never, negative sign
  3. * / %
  4. + -
  5. < > <= >=
  6. == !=
  7. with
  8. either

Short-circuit assessment

a with b    # a false → not evaluated b
a either b  # a → right to evaluate b
