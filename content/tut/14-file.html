Cat++ có thể đọc, ghi file và tương tác với hệ thống.

1. Đọc file

paw content = read_file("/etc/hostname")
meow content

2. Ghi file

write_file("/tmp/hello.txt", "Xin chao!")
meow read_file("/tmp/hello.txt")

3. Ghi thêm vào file

write_file("/tmp/log.txt", "Dong 1\n")
append_file("/tmp/log.txt", "Dong 2\n")
append_file("/tmp/log.txt", "Dong 3\n")
meow read_file("/tmp/log.txt")

4. Đọc theo dòng

write_file("/tmp/data.txt", "mot\nhai\nba\n")
paw lines = read_lines("/tmp/data.txt")
groom line of lines
    meow line

Kết quả:

mot
hai
ba

5. Ghi danh sách theo dòng

write_lines("/tmp/out.txt", ["alpha", "beta", "gamma"])
meow read_file("/tmp/out.txt")

6. Kiểm tra file tồn tại

sniff exists("/etc/passwd")
    meow "Co file passwd"

sniff is_file("/tmp")
    meow "khong phai file"
swat
    meow "khong phai file"

sniff is_dir("/tmp")
    meow "/tmp la thu muc"

7. Liệt kê thư mục

paw files = list_dir("/tmp")
groom f of files
    meow f

8. Xóa file, tạo thư mục

make_dir("/tmp/myapp")
write_file("/tmp/myapp/data.txt", "test")
meow exists("/tmp/myapp/data.txt")
remove_file("/tmp/myapp/data.txt")

9. Biến môi trường

meow env("HOME")
meow env("USER")
meow env("PATH")

10. Ví dụ: đếm từ trong file

write_file("/tmp/text.txt", "hello world from catpp\n")
paw content = read_file("/tmp/text.txt")
paw words = shred(content, " ")
meow len(words)

11. Ví dụ: ghi log

purr log(msg)
    paw t = timestamp()
    append_file("/tmp/app.log", cast(str, t) + ": " + msg + "\n")

log("Chuong trinh bat dau")
log("Xu ly du lieu")
log("Hoan thanh")
meow read_file("/tmp/app.log")

Bài tập

  1. Viết chương trình sao chép file.
  2. Đếm số dòng, số từ, số ký tự trong file.
  3. Viết hàm tìm kiếm chuỗi trong file, in ra số dòng có chứa.
