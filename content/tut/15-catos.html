CatOS là hệ điều hành nhỏ chạy code Cat++ trực tiếp trên bare metal.

1. CatOS là gì?

CatOS là một kernel viết bằng C. Nó nhúng runtime Cat++ and chạy code Cat++ mà không cần Linux, Windows, hay bất kỳ OS nào khác.

2. Kiến trúc

Cat++ code (.cat)
      │
      ▼
Transpiler (tools/transpiler.py)
      │
      ▼
C code (.c)
      │
      ▼
GCC -ffreestanding
      │
      ▼
Object (.o)
      │
      ▼
Linker (kernel/linker.ld)
      │
      ▼
Kernel binary (catos.elf)
      │
      ▼
QEMU / máy thật

3. Cấu trúc project

~/catpp/
├── tools/
│   └── transpiler.py          # Cat++ → C
├── runtime/
│   ├── catpp_rt.h             # Header chung
│   └── catpp_freestanding.c   # VGA, serial, memory
├── kernel/
│   ├── main.c                 # Entry point
│   ├── entry.s                # Assembly boot
│   ├── linker.ld              # Linker script
│   └── demo.cat               # Code Cat++ demo
├── libc/                      # Freestanding headers
│   ├── stdint.h
│   ├── stddef.h
│   └── ...
└── build_catos.sh             # Build script

4. Syntax low-level for CatOS

CatOS use cú pháp low-level — không có sẵn trên web IDE.

Bit operations

paw mask = 0xFF & 0x0F
paw shifted = 1 << 4
paw color = (0x0F << 8) | ord("H")

Cast and pointer

paw vga = cast(ptr, 0xB8000)
# Địa chỉ VGA text mode in bộ nhớ

Struct C-layout

struct Color
    r: u8
    g: u8
    b: u8

paw red = Color(255, 0, 0)
meow red.r

Volatile — for MMIO

volatile paw status = 0

Inline assembly

asm("cli")   # disable interrupts
asm("hlt")   # halt CPU

5. Viết kernel code

File kernel/demo.cat:

meow "Hello from Cat++ in kernel!"

paw x = 10
paw y = 20
meow x + y

paw i = 0
knead i < 5
    meow i
    i++

purr square(n)
    give n * n

meow square(7)

Khi boot, output hiện trên màn hình VGA:

6. Build CatOS

cd ~/catpp
bash build_catos.sh

Build steps:

  1. Transpile demo.cat → demo.c
  2. Compile entry.s, main.c, runtime, demo.c with -m32 -ffreestanding
  3. Link thànhcatos.elf
  4. (Tùy chọn) Createcatos.iso with GRUB

7. Run CatOS

Not cần ISO, QEMU boot ELF kernel trực tiếp:

qemu-system-x86_64 -kernel kernel/catos.elf -m 128M -serial stdio

Hoặc with cửa sổ đồ họa:

qemu-system-x86_64 -kernel kernel/catos.elf -m 128M

8. Runtime freestanding

In CatOS, các builtin hoạt động khác:

Trên LinuxTrên CatOS
meow → printfmeow → VGA + serial
read_file → open❌ Chưa có filesystem
dice → RNG❌ Cần RNG section cứng
cpp → ctypes❌ None

9. Giới hạn hiện tại

  • None keyboard input
  • None filesystem
  • None process
  • Chỉ hỗ trợ subset Cat++ (meow, paw, sniff, knead, purr, struct, cast)
  • Chưa có heap allocator thật

10. Hướng phát triển

  • Keyboard driver (IRQ1)
  • PIT timer interrupt
  • Heap allocator thật (thay bump)
  • Shell đọc lệnh from keyboard
  • Filesystem (FAT16/FAT32)
