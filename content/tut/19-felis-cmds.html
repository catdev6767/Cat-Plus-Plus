Felis OS có 23 lệnh shell chia làm 3 nhóm.

1. System commands

LệnhChức năng
helpDanh sách lệnh
infoThông tin hệ thống
unameTên OS
whoamiTên user
memThông tin RAM

2. Filesystem commands

LệnhChức năng
lsLiệt kê file
cat FILEĐọc file
touch FILETạo file rỗng
mkdir DIRTạo thư mục
rm FILEXóa file
write FILE TEXTGhi file
append FILE TEXTThêm vào file
wc FILEĐếm từ/ký tự

3. Utilities

LệnhChức năng
echo TEXTIn text
historyLịch sử lệnh
clearXóa màn hình
sleep NĐợi N giây
haltDừng CPU
rebootKhởi động lại

4. Ví dụ

felis$ touch notes.txt
felis$ write notes.txt Hello Felis
felis$ cat notes.txt
Hello Felis
felis$ wc notes.txt
Lines: 1 Words: 2 Chars: 11

Bài tập

  1. Tạo 5 file với nội dung khác nhau.
  2. Đếm số từ trong mỗi file bằng wc.
