Felis OS dùng RAM filesystem — lưu file trong bộ nhớ.

1. Cấu trúc

#define MAX_FILES 64
#define MAX_NAME  32
#define MAX_DATA  2048

struct FileEntry {
    char name[32];
    char data[2048];
    int size;
    int used;
    int is_dir;
};
FileEntry fs_files[64];

2. Giới hạn

Thông sốGiá trị
Số file tối đa64
Tên file31 ký tự
Kích thước file2047 byte
Thư mụcChỉ flat (chưa có subdirs)

3. Hoạt động

  • Tạo file: touch name.txt
  • Ghi: write name.txt content
  • Đọc: cat name.txt
  • Xóa: rm name.txt

4. Lưu ý

Mất khi tắt: RAM filesystem mất hết khi reboot. Không có persistence.

Bài tập

  1. Tạo file test.txt, ghi 100 ký tự.
  2. Đọc lại bằng cat.
  3. Kiểm tra kích thước bằng wc.
