Felis OS quản lý bộ nhớ đơn giản — không có paging, không có heap allocator.

1. Memory layout

0x00000000 - 0x000FFFFF:  BIOS, VGA, bootloader (1MB)
0x00100000 - ...        :  Kernel (loaded by GRUB)
0xB8000                 :  VGA text buffer
0xC0000000 - ...        :  (không dùng)

2. Stack

/* entry.s */
.section .bss
.align 16
stack_bottom:
    .skip 16384      /* 16 KB stack */
stack_top:

3. Heap đơn giản (bump allocator)

static uint8_t* heap_ptr = (uint8_t*)0x100000;
static uint8_t* heap_end = (uint8_t*)0x400000;

void* kmalloc(size_t n) {
    if (heap_ptr + n > heap_end) return NULL;
    void* p = heap_ptr;
    heap_ptr += n;
    return p;
}

/* Không có free() */

4. Filesystem trong RAM

FileEntry fs_files[64];
/* Mỗi entry: name 32B + data 2048B = 2080B */
/* Tổng: 64 × 2080 = 133 KB */

5. Giới hạn

Giới hạnGiá trị
RAM128 MB (QEMU)
Kernel dùng~30 KB
Filesystem~133 KB
Stack16 KB

Bài tập

  1. Thêm kfree() đơn giản (mark free, không reuse).
  2. Giảm MAX_FILES xuống 32 → tiết kiệm RAM.
