Error cú pháp

1. Thụt lề sai

purr test()
meow "hi"

Error: Can 'NEWLINE', gap 'MEOW'

Sửa:

purr test()
    meow "hi"

2. Trộn tab and space

purr test()
\tmeow "hi"    # tab
    meow "yo"  # space

Sửa: Chỉ use space. 4 spaces mỗi cấp.

3. Thiếu dấu đóng ngoặc

paw x = (5 + 3

Error: Can ')', gap 'NEWLINE'

Sửa: paw x = (5 + 3)

4. Use the keyword làm name variable

paw meow = "hi"

Error: Not parse is — meow là keyword.

Sửa: paw greeting = "hi"

5. Quên dấu hai chấm in struct

struct Point
    x i32
    y i32

Error: Can ':', gap 'IDENT'

Sửa:

struct Point
    x: i32
    y: i32

6. String chưa đóng

meow "hello

Error: Unterminated string

Sửa: meow "hello"

7. Dùng = thay vì ==

sniff x = 5
    meow "yes"

Error: Parse thành gán, không must compare.

Sửa: sniff x == 5

8. Dấu chấm phẩy thừa

paw x = 5;
meow x;

Error: Cat++ không use ; như C.

Sửa: Bỏ hết ;.
