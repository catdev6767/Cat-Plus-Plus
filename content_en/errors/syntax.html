Lỗi cú pháp

1. Thụt lề sai

purr test()
meow "hi"

Lỗi: Can 'NEWLINE', gap 'MEOW'

Sửa:

purr test()
    meow "hi"

2. Trộn tab và space

purr test()
\tmeow "hi"    # tab
    meow "yo"  # space

Sửa: Chỉ dùng space. 4 spaces mỗi cấp.

3. Thiếu dấu đóng ngoặc

paw x = (5 + 3

Lỗi: Can ')', gap 'NEWLINE'

Sửa: paw x = (5 + 3)

4. Dùng từ khóa làm tên biến

paw meow = "hi"

Lỗi: Không parse được — meow là từ khóa.

Sửa: paw greeting = "hi"

5. Quên dấu hai chấm trong struct

struct Point
    x i32
    y i32

Lỗi: Can ':', gap 'IDENT'

Sửa:

struct Point
    x: i32
    y: i32

6. String chưa đóng

meow "hello

Lỗi: Unterminated string

Sửa: meow "hello"

7. Dùng = thay vì ==

sniff x = 5
    meow "yes"

Lỗi: Parse thành gán, không phải so sánh.

Sửa: sniff x == 5

8. Dấu chấm phẩy thừa

paw x = 5;
meow x;

Lỗi: Cat++ không dùng ; như C.

Sửa: Bỏ hết ;.
