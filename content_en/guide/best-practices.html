Best Practices

Quy ước viết Cat++ sạch, dễ đọc, dễ bảo trì.

1. Đặt tên

Variable — snake_case

# Tốt
paw cat_name = "Tom"
paw total_count = 0
paw max_speed = 100

# Xấu
paw catName = "Tom"
paw TotalCount = 0
paw x = 0

Function — snake_case

# Tốt
purr find_max(arr)
purr read_config(path)
purr is_valid_email(s)

# Xấu
purr findMax(arr)
purr FindMax(arr)
purr f(arr)

Class — PascalCase

# Tốt
cat Point
cat Animal
cat HttpRequest

# Xấu
cat point
cat animal
cat http_request

Hằng — UPPER_SNAKE_CASE

paw MAX_SIZE = 100
paw PI = 3.14159
paw DEFAULT_TIMEOUT = 30

Private field — gạch dưới đầu

cat Person
    paw _name
    paw _age

    purr get name()
        give me._name

2. Thụt lề

# True — 4 spaces
purr test()
    sniff x > 0
        meow "positive"
    swat
        meow "negative"

# False — trộn tab and space
purr test()
\tmeow "hi"
    meow "world"

3. Độ dài dòng

# Tốt — dưới 80 ký tự
paw result = compute(
    first_arg,
    second_arg,
    third_arg
)

# Xấu — quá dài
paw result = compute(first_arg, second_arg, third_arg, fourth_arg, fifth_arg, sixth_arg)

4. Comment

Explanation TẠI SAO, không must LÀM GÌ

# Tốt — giải thích lý do
# Dùng sqrt để tránh thử chia hết tới n
# faster 10x cho số lớn
purr is_prime(n)
    paw i = 2
    knead i * i <= n
        ...

# Xấu — lặp lại code
# Tăng i lên 1
paw i = i + 1

Comment cho hàm complex

# Tìm section tử trong mảng already sắp xếp bằng binary search.
# Return chỉ số or -1 if không tìm thấy.
# Độ complex: O(log n)
purr binary_search(arr, target)
    ...

5. Chia hàm nhỏ

# Tốt — mỗi hàm 1 việc
purr read_scores(path)
    give read_lines(path)

purr parse_scores(lines)
    paw scores = []
    groom line of lines
        paw scores = scores + [cast(float, line)]
    give scores

purr average(scores)
    sniff len(scores) == 0
        give 0
    give pile(scores) / len(scores)

# Dùng
paw lines = read_scores("data.txt")
paw scores = parse_scores(lines)
meow average(scores)

6. Xử lý lỗi

Dùng try/hiss cho code can lỗi

# Tốt
tap
    paw n = cast(int, user_input)
    meow n * 2
hiss e
    meow "Khong phai so: " + user_input

# Xấu — code crash
paw n = cast(int, user_input)

Check điều kiện biên

# Tốt
purr divide(a, b)
    sniff b == 0
        give hungry
    give a / b

# Xấu
purr divide(a, b)
    give a / b   # Error if b == 0

7. Tránh lặp code

# Xấu — lặp 3 lần
meow "Ten: " + user1.name
meow "Tuoi: " + cast(str, user1.age)
meow "Dia chi: " + user1.address
meow "Ten: " + user2.name
meow "Tuoi: " + cast(str, user2.age)
...

# Tốt — hàm
purr print_user(u)
    meow "Ten: " + u.name
    meow "Tuoi: " + cast(str, u.age)
    meow "Dia chi: " + u.address

print_user(user1)
print_user(user2)

8. Magic numbers

# Xấu
sniff score > 90
    meow "A"
sniff score > 80
    meow "B"

# Tốt
paw GRADE_A = 90
paw GRADE_B = 80

sniff score > GRADE_A
    meow "A"
sniff score > GRADE_B
    meow "B"

9. Xử lý danh sách

# Tốt — use builtin
paw nums = [1, 2, 3, 4, 5]
paw squares = chase(nums, kit(x) => x * x)
paw evens = sift(nums, kit(x) => x % 2 == 0)

# Xấu — tự viết vòng lặp
paw squares = []
paw i = 0
knead i < len(nums)
    paw squares = squares + [nums[i] * nums[i]]
    i++

10. Cấu trúc file

# 1. Comment đầu file
# 2. Import
use "mathlib.cat"

# 3. Hằng số
paw PI = 3.14159
paw MAX = 100

# 4. Function tiện ích
purr helper1()
purr helper2()

# 5. Function chính
purr main()
    ...

# 6. Run
main()

11. Checklist trước khi commit

  • Tên biến/hàm rõ nghĩa
  • Thụt lề 4 spaces, không tab
  • Dòng dưới 80 ký tự
  • Comment giải thích "tại sao"
  • Xử lý lỗi bằng try/hiss
  • Not magic number
  • Not lặp code
  • Test với input biên (0, âm, rỗng)
