CLI — paw

paw is the official Cat++ CLI. Run scripts, create files, transpile, format, lint, REPL.

Install

ln -sf ~/catpp/paw/paw ~/.local/bin/paw
ln -sf ~/catpp/pawedit/pawedit ~/.local/bin/pawedit

Commands

paw run FILE.cat

Run script via fastest engine (PyCompiler first, fallback interpreter).

$ paw run hello.cat
Hello, Cat++!

paw new FILE.cat

Create a new file with template and open in PawEditor.

$ paw new game.cat
Created: game.cat

paw edit FILE.cat

Open an existing file in PawEditor.

paw repl

Interactive REPL. Type exit to quit.

$ paw repl
paw REPL — type 'exit' to quit
paw> meow 2 + 2
4
paw> paw x = 10
paw> meow x * 3
30
paw> exit

paw build FILE.cat

Transpile to C (boxed, uses Value struct). Runs any code.

$ paw build hello.cat
Built: hello.c
Binary: hello

paw build-fast FILE.cat

Transpile to native C (int32_t, double). Requires full type annotations. 13,635x faster than interpreter.

$ paw build-fast calc.cat
Built: calc.native.c
Binary: calc.native  (13,635x faster than interpreter)

paw fmt FILE.cat

Format code: normalize indent to 4 spaces, trim trailing whitespace, collapse blank lines.

$ paw fmt game.cat
--- game.cat
+++ game.cat
@@ -1,3 +1,3 @@
-paw x=1
+paw x = 1

$ paw fmt game.cat --write    # save to file

paw lint FILE.cat

Check for syntax errors, tabs, trailing whitespace, long lines, same-scope redefinitions.

$ paw lint game.cat
game.cat:5: warn: 'x' redefined at same scope (first at line 4)

1 issue(s): 0 error, 1 warning

paw check FILE.cat

Count type coverage. Tells you if native compile is possible.

$ paw check calc.cat
File: calc.cat
  Functions: 2/2 fully typed
  Params:    4/4 typed
  Variables: 3/3 typed

✓ Can compile native (13,635x faster)

PawEditor

Nano-like editor for Cat++.

pawedit hello.cat
KeyFunction
^SSave
^OSave As
^WFind
^GGoto line
^KCut line
^UPaste line
^XExit

Example workflow

# 1. Create a new script
paw new calc.cat

# 2. Edit in the editor (Ctrl+S to save, Ctrl+X to exit)

# 3. Lint + check
paw lint calc.cat
paw check calc.cat

# 4. Try running
paw run calc.cat

# 5. Compile native
paw build-fast calc.cat

# 6. Run binary
./calc.native
