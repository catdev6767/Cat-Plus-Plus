Hiểu sâu về interpreter: from source code to output.

2. Lexer

Read fromng ký tự, tạo token. Xử lý:

  • Number: 42, 3.14, 0xFF, 0b1010
  • String: "hello" with escape \n \t \"
  • Identifiers: foo, bar_baz
  • From khóa: meow, paw, purr
  • Toán tử: + - * / % == != & | << >>
  • Layout: INDENT, DEDENT, NEWLINE

Examples

paw x = 42

Tokenize thành:

PAW("paw")  IDENT("x")  ASSIGN("=")  NUMBER(42)  NEWLINE

3. Parser

Nhận tokens, tạo AST (Abstract Syntax Tree). Dùng recursive descent — mỗi function parse một loại cấu trúc.

Precedence chain (from thấp to cao)

expr
 ├── or_          (or, either)
 ├── and_         (and, with)
 ├── not_         (not, never)
 ├── in_          (in)
 ├── bit_or       (|)
 ├── bit_xor      (^)
 ├── bit_and      (&)
 ├── shift        (<<, >>)
 ├── cmp          (==, !=, <, >, <=, >=)
 ├── add          (+, -)
 ├── mul          (*, /, %)
 ├── unary        (-, ~)
 └── postfix      (call, index, dot)

Examples AST

paw x = 1 + 2 * 3

Parse thành:

('let', 'x',
  ('+', ('num', 1),
        ('*', ('num', 2), ('num', 3))))

Vì * có precedence cao hơn +, should 2*3 is nhóm trước.

4. Interpreter

Duyệt AST. Mỗi node có function eval_() (biểu thức) or exec_() (câu lệnh).

Environment (scope)

class Env:
    vars: dict          # variable in scope này
    parent: Env         # scope cha

Khi tìm variable `x`:
1. If x in vars → trả về
2. If không → tìm in parent (đệ quy)
3. If không có → lỗi

Examples scope

paw x = 10          # global

purr f()
    paw y = 20      # local
    meow x          # đọc is x (global)
    meow y          # đọc is y (local)

f()                 # OK
meow y              # LỖI — y chỉ tồn tại in f

6. Exceptions

Dùng Python exception để điều khiển luồng:

  • ReturnEx — thoát function return value
  • StopEx — thoát loop (sit)
  • SkipEx — bỏ qua lần lặp (leap)
  • CatError — lỗi runtime (chia 0, variable chưa khai báo)
# Khi gặp `give x`:
raise ReturnEx(value)

# In function:
try:
    for stmt in body: exec_(stmt)
except ReturnEx as e:
    return e.v

7. Module system

3 file:

  • core/registry.py — đăng ký API giữa modules
  • core/bus.py — event bus
  • core/loader.py — auto-load modules

Interpreter đăng ký with registry:

class InterpreterModule(BaseModule):
    def setup(self):
        self.registry.set('interpreter', self)

    def run(self, code):
        return run_catpp(code)

Module khác gọi qua registry:

interp = self.registry.get('interpreter')
result = interp.run("meow \"hi\"")

9. Transpiler Cat++ → C

Khác with interpreter. Not thực thi AST mà sinh C code.

# Cat++ AST
('let', 'x', ('+', ('num', 1), ('num', 2)))

# C code sinh ra
long x = (1 + 2);

Dùng 2-pass:

  1. Pass 1: scan struct, infer return types
  2. Pass 2: generate C code

10. Giới hạn hiệu năng

Interpreter tree-walking slower C khoảng 100x. Lý do:

  • Mỗi biểu thức duyệt AST (function call overhead)
  • Type động (check type runtime)
  • Python VM (slower native)
  • None JIT

Muốn faster:

  • Compile to bytecode (nhanh 5-10x)
  • Transpile C (nhanh gần bằng C)
  • JIT with LLVM (nhanh bằng C)
