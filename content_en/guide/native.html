Native Transpiler — Nhanh gần C++

Cat++ có 2 transpiler to C:

  • → C (boxed) — use Value động, chạy mọi code, slower
  • ⚡ C fast (native) — sinh C native (int32_t, double), nhanh gần C++, yêu cầu type annotation

Cách use

Thêm type annotation for variable and function:

purr sum_to(n: i32) -> i64
    paw total: i64 = 0
    paw i: i32 = 1
    knead i <= n
        total = total + i
        i = i + 1
    give total

meow sum_to(1000000)

Ấn ⚡ C fast (Ctrl+Shift+N) để xem C code native.

Warning overflow

i32 chỉ chứa is tối đa ~2.1 tỷ. Khi accumulate số lớn, use i64:

paw total: i64 = 0       # ✓
paw total: i32 = 0       # ✗ tràn ở 2.1 tỷ

Đây là hành vi giống hệt C/C++.

Khi nào use native

  • Code số học nặng (loop, calculate)
  • Thuật toán (sort, search, fibonacci)
  • Benchmark, compare

Khi không cần native:

  • Code có list/dict/class complex (use boxed)
  • Code ngắn, không cần tốc độ
  • Prototype nhanh (không cần type)
