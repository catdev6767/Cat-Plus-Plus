Performance Guide

Cách viết code Cat++ chạy nhanh.

1. Hiệu năng hiện tại

Cat++ chạy qua Python interpreter. Chậm hơn C khoảng 100x.

2. Quy tắc chung

Tránh tính lại in loop

# Xấu — tính len(arr) each time
paw i = 0
knead i < len(arr)
    meow arr[i]
    i++

# Tốt — cache lại
paw n = len(arr)
paw i = 0
knead i < n
    meow arr[i]
    i++

Dùng variable tạm for loop lồng

# Xấu
paw i = 0
knead i < n
    paw j = 0
    knead j < len(arr) - i - 1
        ...
        j++
    i++

# Tốt
paw i = 0
knead i < n
    paw limit = len(arr) - i - 1
    paw j = 0
    knead j < limit
        ...
        j++
    i++

Chọn cấu trúc phù hợp

# Tìm kiếm in list — chậm O(n)
sniff hunt(arr, target)
    ...

# Tra cứu in dict — nhanh O(1)
sniff seek(dict, key)
    ...

3. Dùng builtin thay vì tự viết

# Xấu — tự tính

# Tốt — use builtin (viết bằng Python, faster)

4. Hạn chế đệ quy

# Xấu — đệ quy chậm
purr fib(n)
    sniff n <= 1
        give n
    give fib(n - 1) + fib(n - 2)

meow fib(30)   # ~2 giây
# Tốt — loop
purr fib(n)
    sniff n <= 1
        give n
    paw a = 0
    paw b = 1
    paw i = 2
    knead i <= n
        paw c = a + b
        paw a = b
        paw b = c
        i++
    give b

meow fib(30)   # ~0.05 giây

Đệ quy có nhớ (memoization)

paw memo = {}

purr fib(n)
    sniff n <= 1
        give n
    sniff seek(memo, n)
        give memo[n]
    paw r = fib(n - 1) + fib(n - 2)
    memo[n] = r
    give r

meow fib(100)   # nhanh

5. Tránh tạo object thừa

# Xấu — tạo list mới mỗi vòng
paw i = 0
knead i < 1000
    paw arr = []
    paw arr = arr + [i]
    i++

# Tốt — tạo 1 lần
paw arr = []
paw i = 0
knead i < 1000
    arr.push(i)
    i++

6. Dùng toán tử bit khi can

# Xấu
paw half = x / 2
paw double = x * 2

# Tốt (chỉ with số nguyên dương)
paw half = x >> 1
paw double = x << 1

7. Break sớm

# Xấu — duyệt hết mới thoát

groom x of arr
    sniff x == target
        paw found = yes

# Tốt — thoát ngay
paw found = no
groom x of arr
    sniff x == target
        paw found = yes
        sit

9. Khi cần faster

If code calculate nặng

  • Transpile to C use tools/transpiler.py
  • Dùng cpp() để gọi C library
  • Viết section nặng bằng C, gọi from Cat++

Examples: tính số nguyên tố

# Cat++ thuần — 5 giây for 100k số
purr is_prime(n)
    sniff n < 2
        give no
    paw i = 2
    knead i * i <= n
        sniff n % i == 0
            give no
        i++
    give yes

10. Kết luận

Cat++ not allowed thiết kế for hiệu năng. If cần nhanh:

  1. Dùng builtin thay vì tự viết
  2. Tránh đệ quy sâu
  3. Cache value in loop
  4. If vẫn chậm → transpile to C
