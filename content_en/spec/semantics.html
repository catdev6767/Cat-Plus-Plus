Expression evaluation

Left to right, respecting precedence:

  1. ()
  2. never, dấu âm
  3. * / %
  4. + -
  5. < > <= >=
  6. == !=
  7. with
  8. either

Đánh giá ngắn mạch

a with b    # a sai → không đánh giá b
a either b  # a đúng → không đánh giá b

Ép type

  • + with string → ép vế còn lại thành string
  • Các phép khác yêu cầu cả hai là số
  • So sánh không ép: 42 == "42" là shake

Truthiness

  • nod → đúng, shake → sai
  • Number khác 0 → đúng
  • String/DS khác rỗng → đúng
  • hungry → sai

Scope

  • Mỗi function có scope riêng
  • Variable in function nhìn thấy variable outside (lexical scope)
  • None keyword global
