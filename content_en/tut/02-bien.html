Variable lưu giá trị để dùng lại. Dùng từ khóa paw.

Khai báo

paw name = "Whiskers"
paw age = 3
meow name
meow age

Gán lại

paw x = 10
x = x + 5
meow x

Result: 15

Nối chuỗi và biến

paw name = "Tom"
meow "Xin chào, " + name + "!"

Lesson tập

Khai báo width = 5, height = 3, in ra diện tích hình chữ nhật.
