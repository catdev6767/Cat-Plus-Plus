Functions group code for reuse.

Define

purr greet(name)
    meow "Hello, " + name + "!"

greet("Tom")
greet("Jerry")

Return value

purr add(a, b)
    give a + b

meow add(3, 4)

Function đệ quy

purr fact(n)
    sniff n <= 1
        give 1
    give n * fact(n - 1)

meow fact(5)
