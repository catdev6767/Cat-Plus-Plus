Class gom dữ liệu và hàm xử lý dữ liệu đó.

Define

cat Point
    paw x
    paw y

    purr new(a, b)
        me.x = a
        me.y = b

    purr dist()
        give scratch(me.x * me.x + me.y * me.y)

paw p = Point(3, 4)
meow p.dist()

Inheritance (kin)

cat Animal
    paw name
    purr new(n)
        me.name = n
    purr speak()
        give "..."

cat Dog kin Animal
    purr speak()
        give me.name + " says woof!"

meow Dog("Rex").speak()

Enum (litter)

litter Color
    red
    green
    blue

meow Color.red
