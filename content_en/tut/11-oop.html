Đi sâu ando OOP nâng cao: static method, getter/setter, abstract class, operator overload.

1. Static method

Method gọi qua class, không cần instance.

cat Math
    purr static square(n)
        give n * n

    purr static cube(n)
        give n * n * n

meow Math.square(5)
meow Math.cube(3)

Result: 25 and 27.

2. Getter and Setter

Run code khi đọc/ghi field. Dùng để kiểm soát truy cập.

cat Temperature
    paw _celsius

    purr new(c)
        me._celsius = c

    purr get fahrenheit()
        give me._celsius * 9 / 5 + 32

    purr set fahrenheit(f)
        me._celsius = (f - 32) * 5 / 9

paw t = Temperature(25)
meow t.fahrenheit

t.fahrenheit = 212
meow t._celsius

3. Abstract class

Not tạo instance is. Class con must override hết method abstract.

cat abstract Shape
    purr area()
    purr name()

cat Circle kin Shape
    paw _r
    purr new(r)
        me._r = r
    purr area()
        give 3.14159 * me._r * me._r
    purr name()
        give "circle"

cat Square kin Shape
    paw _side
    purr new(s)
        me._side = s
    purr area()
        give me._side * me._side
    purr name()
        give "square"

paw shapes = [Circle(2), Square(3)]
groom s of shapes
    meow s.name() + ": " + cast(str, s.area())

4. Operator overload

Define lại toán tử cho class.

cat Vec2
    paw x
    paw y

    purr new(x, y)
        me.x = x
        me.y = y

    purr add(o)
        give Vec2(me.x + o.x, me.y + o.y)

    purr sub(o)
        give Vec2(me.x - o.x, me.y - o.y)

    purr mul(k)
        give Vec2(me.x * k, me.y * k)

    purr eq(o)
        give me.x == o.x and me.y == o.y

    purr show()
        give "(" + cast(str, me.x) + ", " + cast(str, me.y) + ")"

paw a = Vec2(1, 2)
paw b = Vec2(3, 4)
meow (a + b).show()
meow (b - a).show()
meow (a * 3).show()
