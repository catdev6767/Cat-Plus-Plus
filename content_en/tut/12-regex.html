Regex (regular expression) là công cụ mạnh để xử lý string theo mẫu.

1. Ba function regex

FunctionChức năng
match(pattern, s)Check có khớp không
find_all(pattern, s)Tìm tất cả string khớp
replace_all(pattern, s, sub)Thay thế tất cả

2. match — check mẫu

sniff match("[0-9]+", "abc123")
    meow "co so"
swat
    meow "khong co so"

sniff match("^[a-z]+$", "hello")
    meow "toan chu thuong"

sniff match("@", "user@example.com")
    meow "co @ in email"

3. find_all — tìm tất cả

meow find_all("[0-9]+", "toi co 3 con meo va 5 con for")
# [3, 5]

meow find_all("[a-z]+", "Hello World Foo")
# [ello, orld, oo]

meow find_all("\\w+@\\w+\\.\\w+", "lien he a@x.com hoac b@y.org")
# [a@x.com, b@y.org]

4. replace_all — thay thế

meow replace_all("[0-9]", "abc123def", "#")
# abc###def

meow replace_all("\\s+", "hello   world  foo", " ")
# hello world foo

meow replace_all("[aeiou]", "hello world", "*")
# h*ll* w*rld

5. Syntax regex thường use

MẫuNghĩa
.Bất kỳ ký tự
\\dChữ số [0-9]
\\wChữ cái, số, _
\\sKhoảng trắng
*0 or nhiều
+1 or nhiều
?0 or 1
[abc]a, b, or c
[^abc]Not must a, b, c
^Start string
$End string
()Nhóm
|Hoặc

6. Examples thực tế: check email

purr is_email(s)
    give match("^[\\w.]+@[\\w.]+\\.[a-z]+$", s)

meow is_email("user@example.com")   # yes
meow is_email("invalid")            # no
