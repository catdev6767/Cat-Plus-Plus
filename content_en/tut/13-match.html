match/case giúp so sánh một giá trị với nhiều khả năng — gọn hơn nhiều sniff lồng nhau.

1. Syntax cơ bản

paw x = 2

match x
    case 1
        meow "mot"
    case 2
        meow "hai"
    case 3
        meow "ba"

Result: hai.

2. Wildcard — nhánh mặc định

paw x = 99

match x
    case 1
        meow "one"
    case 2
        meow "two"
    case _
        meow "khac"

3. Match với chuỗi

paw cmd = "hello"

match cmd
    case "hi"
        meow "chao"
    case "hello"
        meow "xin chao"
    case "bye"
        meow "tam biet"

4. Match với kết quả hàm

purr color_code(c)
    match c
        case "red"
            give 1
        case "green"
            give 2
        case "blue"
            give 3
        case _
            give 0

meow color_code("green")

5. Ứng dụng: xử lý menu

purr menu(choice)
    match choice
        case 1
            meow "Them san pham"
        case 2
            meow "Xoa san pham"
        case 3
            meow "Xem danh sach"
        case 4
            meow "Thoat"
        case _
            meow "Lua chon khong hop le"

menu(2)

6. Ứng dụng: xếp loại điểm

purr grade(score)
    sniff score >= 90
        give "A"
    sniff score >= 80
        give "B"
    sniff score >= 70
        give "C"
    give "F"

meow grade(85)

Bài này không dùng match được vì match so sánh bằng, không so sánh khoảng.

7. So sánh với sniff/swat

Dùng sniff lồng nhau:

sniff x == 1
    meow "mot"
swat
    sniff x == 2
        meow "hai"
    swat
        sniff x == 3
            meow "ba"
        swat
            meow "khac"

Dùng match:

match x
    case 1
        meow "mot"
    case 2
        meow "hai"
    case 3
        meow "ba"
    case _
        meow "khac"

Lesson tập

  1. Viết hàm day_of_week(n) — nhận 1-7, trả về tên thứ.
  2. Viết hàm calc(op) — nhận "+", "-", "*", "/", thực hiện phép tính.
  3. Viết chương trình đơn giản mô phỏng menu máy ATM.
