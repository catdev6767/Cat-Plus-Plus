Cat++ có 3 engine chạy code. Mỗi cái có tốc độ khác nhau.

1. Ba engine

EngineTốc độCách hoạt động
Interpreter1xDuyệt AST, eval từng node
Bytecode VM2-3xAST → bytecode → stack machine
PyCompiler20-50xAST → Python source → exec()

2. Tự động chọn

Server tự động:

  1. Thử PyCompiler trước (nhanh nhất)
  2. Nếu lỗi → Bytecode VM
  3. Nếu vẫn lỗi → Interpreter
