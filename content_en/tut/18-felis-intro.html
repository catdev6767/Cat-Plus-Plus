Felis OS là hệ điều hành nhỏ, boot bare metal. Viết bằng C + runtime Cat++.

1. Đặc điểm

Đặc điểmValue
Kernel size~30 KB
Boot time< 1 giây
Commands23 lệnh
FilesystemRAM (64 file, 2KB/file)
Kiến trúcx86 32-bit

2. Boot flow

Nguồn
    ↓
BIOS POST
    ↓
GRUB (multiboot)
    ↓
Load kernel ando 0x100000
    ↓
_start (assembly)
    ↓
kmain() → shell

3. Cấu trúc source

kernel/
├── entry.s      Assembly entry
├── main.c       kmain()
├── idt.c        Interrupt table
├── irq.s        IRQ stubs
├── keyboard.c   PS/2 driver
├── string.c     strlen, strcpy, ...
├── fs.c         RAM filesystem
├── commands.c   23 commands
├── shell.c      REPL + line editor
└── linker.ld    Memory layout

4. Run Felis OS

bash build_felis.sh
qemu-system-x86_64 -kernel kernel/felis.elf \
    -m 128M -display curses -nodefaults -snapshot

Lesson tập

  1. Boot Felis OS trong QEMU.
  2. Run lệnh help xem danh sách.
  3. Run info, uname, mem.
