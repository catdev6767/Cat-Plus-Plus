Felis OS dùng RAM filesystem — lưu file trong bộ nhớ.

1. Cấu trúc

#define MAX_FILES 64
#define MAX_NAME  32
#define MAX_DATA  2048

struct FileEntry {
    char name[32];
    char data[2048];
    int size;
    int used;
    int is_dir;
};
FileEntry fs_files[64];

2. Giới hạn

Thông sốValue
Number file tối đa64
Tên file31 ký tự
Kích thước file2047 byte
Thư mụcChỉ flat (chưa có subdirs)

3. Hoạt động

  • Create file: touch name.txt
  • Write: write name.txt content
  • Read: cat name.txt
  • Delete: rm name.txt

4. Note

Mất khi tắt: RAM filesystem mất hết khi reboot. None persistence.
