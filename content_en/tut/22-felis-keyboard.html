Cách Felis OS đọc bàn phím qua PS/2 controller.

1. Cổng I/O

PortChức năng
0x60Keyboard data
0x64Keyboard status/command

2. Read scancode

uint8_t scancode = inb(0x60);

/* Bit 7 = key release */
if (scancode & 0x80) return;

/* Scancode → ASCII */
char c = scancode_map[scancode];

3. Shift/Caps

/* Shift = scancode 0x2A or 0x36 */
if (sc == 0x2A || sc == 0x36) {
    shift = 1;
    return;
}

/* Release shift */
if (released == 0x2A || released == 0x36) {
    shift = 0;
    return;
}

4. Bảng scancode

static const char map_lower[128] = {
    [0x1E] = 'a',
    [0x1F] = 's',
    [0x20] = 'd',
    [0x1C] = '\n',
    [0x39] = ' ',
    ...
};

5. Special keys

MãPhím
0xE0 + 0x48↑ (up)
0xE0 + 0x50↓ (down)
0xE0 + 0x4B← (left)
0xE0 + 0x4D→ (right)

Lesson tập

  1. Thêm phím F1-F12 ando bảng scancode.
  2. Thêm hỗ trợ Ctrl+C để hủy lệnh.
