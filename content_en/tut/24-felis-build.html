Cách Felis OS is biên dịch từ source C + Assembly thành kernel ELF.

1. Compiler flags

-m32                  # 32-bit
-ffreestanding        # None OS
-fno-pic              # Not position-independent
-fno-stack-protector  # Not stack canary
-fno-builtin          # Not builtin functions
-nostdlib -nostdinc   # Not standard library
-Wall -O2             # Warnings + optimize

2. Include paths

-I libc      # stdint.h, stddef.h
-I runtime   # catpp_rt.h
-I kernel    # utils.h

3. Build steps

# 1. Compile .c → .o
gcc $CFLAGS -c kernel/main.c -o kernel/main.o

# 2. Compile .s → .o (assembly)
gcc $CFLAGS -c kernel/entry.s -o kernel/entry.o

# 3. Link tất cả
ld -m elf_i386 -T linker.ld -nostdlib \
   kernel/entry.o kernel/main.o ... \
   $(gcc -m32 -print-libgcc-file-name) \
   -o kernel/felis.elf

4. Linker script

ENTRY(_start)

SECTIONS {
    . = 1M;                    /* Load tại 1MB */

    .multiboot : ALIGN(4K) { *(.multiboot) }
    .text      : ALIGN(4K) { *(.text) }
    .rodata    : ALIGN(4K) { *(.rodata) }
    .data      : ALIGN(4K) { *(.data) }
    .bss       : ALIGN(4K) { *(COMMON) *(.bss) }
}

5. Tại sao load tại 1MB?

Vùng 0-1MB dành cho BIOS, VGA buffer, bootloader. Kernel must be trên 1MB.

Lesson tập

  1. Sửa linker script load kernel tại 2MB.
  2. Thêm -Os thay vì -O2 → compare kích thước.
