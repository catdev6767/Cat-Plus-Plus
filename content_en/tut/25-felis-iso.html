Create file ISO boot from USB như Linux distro.

1. Cấu trúc ISO

iso/
├── boot/
│   ├── felis.elf      kernel
│   └── grub/
│       └── grub.cfg   cấu hình GRUB

2. grub.cfg

set timeout=3
set default=0

menuentry "Felis OS v0.2" {
    multiboot /boot/felis.elf
    boot
}

3. Create ISO

grub-mkrescue -o felis.iso iso

GRUB tự thêm:

  • El Torito boot record
  • BIOS boot sector
  • EFI boot partition

4. Test ISO

qemu-system-x86_64 -cdrom felis.iso -m 128M -display curses

Sẽ hiện GRUB menu → chọn "Felis OS" → boot.

5. Write ra USB

# Xem USB
lsblk

# Write (CẨN THẬN — xóa hết USB)
sudo dd if=felis.iso of=/dev/sdX bs=4M status=progress
sync

6. Boot máy thật

  1. Cắm USB ando máy
  2. Khởi động → F12/F2 → chọn USB
  3. Felis OS boot from USB

Exercises
