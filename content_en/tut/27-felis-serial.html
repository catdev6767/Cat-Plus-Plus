Serial port (COM1) giúp debug kernel qua terminal.

1. Port COM1

PortChức năng
0x3F8Data register
0x3F9Interrupt enable
0x3FAFIFO control
0x3FBLine control
0x3FCModem control
0x3FDLine status

2. Khởi tạo

void serial_init(void) {
    outb(COM1 + 1, 0x00);  /* Disable interrupts */
    outb(COM1 + 3, 0x80);  /* Enable DLAB */
    outb(COM1 + 0, 0x03);  /* Divisor: 38400 baud */
    outb(COM1 + 1, 0x00);
    outb(COM1 + 3, 0x03);  /* 8 bits, no parity, 1 stop */
    outb(COM1 + 2, 0xC7);  /* Enable FIFO */
    outb(COM1 + 4, 0x0B);  /* IRQs enabled, RTS/DSR */
}

3. Gửi ký tự

void serial_putc(char c) {
    while (!(inb(COM1 + 5) & 0x20));  /* Wait for empty */
    outb(COM1, c);
}

4. Nhận ký tự

int serial_has_data(void) {
    return inb(COM1 + 5) & 0x01;
}

char serial_getchar(void) {
    while (!serial_has_data());
    return inb(COM1);
}

5. Debug trong QEMU

qemu-system-x86_64 -kernel felis.elf -serial stdio -display none

Output serial hiện ra terminal.
