Đồ án tổng hợp — tạo một mini game or ứng dụng chạy trong Felis OS.

1. Đề lesson: Game đoán số

Viết lệnh guess để chơi đoán số. Máy chọn số 1-100, người use đoán.

Yêu cầu

  • Lưu số bí mật trong biến static
  • Mỗi lần gọi guess N → check
  • Print "cao hon" or "thap hon"
  • True → in số lần đoán

2. Gợi ý code

static int secret = 0;
static int tries = 0;

static void cmd_guess(char* arg) {
    if (secret == 0) {
        /* Khởi tạo */
        secret = 42;
        tries = 0;
        catpp_print_str("Da chon so 1-100. Doan di!");
        return;
    }
    int n = 0;
    while (*arg >= '0' && *arg <= '9') {
        n = n * 10 + (*arg - '0');
        arg++;
    }
    tries++;
    if (n < secret) catpp_print_str("Cao hon");
    else if (n > secret) catpp_print_str("Thap hon");
    else {
        catpp_print_str("Dung roi!");
        /* Printing numbers lần đoán */
        secret = 0;
    }
}

3. Test

felis$ guess
Da chon so 1-100. Doan di!
felis$ guess 50
Thap hon
felis$ guess 25
Cao hon
felis$ guess 42
Dung roi!
