# Cat++ Tools

Real-world CLI tools built in Cat++ — proof it works for daily tasks.

## Usage

    catpp run examples/tools/<name>.cat
    paw run examples/tools/<name>.cat

## Tools

| Tool | What it does |
|---|---|
| github-stats.cat | Show GitHub user stats |
| weather.cat | Show weather (no API key) |
| ip-info.cat | Show public IP info |
| json-format.cat | Pretty-print JSON from URL |
| sys-info.cat | Show system info |

## Customize

Edit config variable at top of each file:

    pawedit examples/tools/weather.cat
