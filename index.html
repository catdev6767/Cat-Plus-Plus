What is Cat++?

Cat++ is a small programming language that runs entirely in the browser. Syntax uses cat-themed keywords — easy to remember, fun, and great for beginners. Can transpile to C to write OS kernels ().

Example

# Hello world
meow "Hello, Cat++!"

# Function with default parameter
purr greet(name, greeting = "Hello")
    give greeting + ", " + name

meow greet("Tom")          # Hello, Tom

# Class with operator overload
cat Vec2
    paw x
    paw y
    purr new(x, y)
        me.x = x
        me.y = y
    purr add(o)
        give Vec2(me.x + o.x, me.y + o.y)

paw c = Vec2(1, 2) + Vec2(3, 4)

Performance — Nearly C++

Cat++ has 4 engines. Pick speed or flexibility as needed. With ⚡ C native, typed code compiles to pure C (int32_t, double) — gcc -O2 optimizes like real C++.

Benchmark — 1 million iterations

purr sum_to(n: i32) -> i64
    paw total: i64 = 0
    paw i: i32 = 1
    knead i <= n
        total = total + i
        i = i + 1
    give total

When to use what?

  • ⚡ C native — heavy arithmetic, algorithms (needs type annotations)
  • C boxed — complex list/dict/class code (runs anything)
  • Interpreter/VM — quick prototyping, no types needed

CLI — paw

paw is the official command-line tool. Run scripts, create files, REPL, transpile, format, lint. 

# Run a script
paw run hello.cat

# Create new file + open editor
paw new game.cat

# Interactive REPL
paw repl

# Transpile to C (13,635× faster)
paw build-fast calc.cat

# Format + lint + check
paw fmt game.cat --write
paw lint game.cat
paw check game.cat

paw run

Run Cat++ script via interpreter (or VM, PyCompiler)

paw build-fast

Transpile to native C — 13,635× faster than interpreter

paw fmt / lint / check

Format code, find errors, check type coverage

PawEditor

Nano-like editor with Cat++ syntax highlight, written in Python + curses

Install

Run directly (no install)

Open IDE — works right in your browser.

One-line install

curl -fsSL https://raw.githubusercontent.com/catdev6767/Cat-Plus-Plus/main/install.sh | bash

Install manually

# Requires: Python 3.8+
git clone https://github.com/catdev6767/Cat-Plus-Plus.git
cd Cat-Plus-Plus
python3 catpp.py

# Open: http://localhost:5000

Docker

docker build -t catpp:2.0 .
docker run -p 5000:5000 catpp:2.0

CLI

python3 catpp.py repl              # REPL
python3 catpp.py run hello.cat     # Run file
python3 catpp.py fmt hello.cat -w  # Format
python3 catpp.py lint hello.cat    # Lint
