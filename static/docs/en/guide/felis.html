Felis OS — Hướng dẫn đầy đủ

Từ Cat++ code tới kernel boot trên bare metal, không Linux, không Python.

1. Tổng quan kiến trúc

┌──────────────────────────────────────┐
│  Cat++ source (.cat)                 │
│  meow, paw, sniff, knead, purr...   │
└──────────────┬───────────────────────┘
               │ transpiler.py
               ▼
┌──────────────────────────────────────┐
│  C source (.c)                       │
│  printf, if, while, typedef struct   │
└──────────────┬───────────────────────┘
               │ gcc -m32 -ffreestanding
               ▼
┌──────────────────────────────────────┐
│  Object files (.o)                   │
└──────────────┬───────────────────────┘
               │ ld + linker.ld
               ▼
┌──────────────────────────────────────┐
│  ELF kernel (felis.elf)              │
└──────────────┬───────────────────────┘
               │ QEMU hoặc GRUB
               ▼
┌──────────────────────────────────────┐
│  Bare metal — CPU chạy trực tiếp     │
└──────────────────────────────────────┘

2. Cấu trúc thư mục

~/catpp/
├── tools/
│   └── transpiler.py              # Bộ dịch Cat++ → C
│
├── runtime/
│   ├── catpp_rt.h                 # Header chung (hosted + freestanding)
│   └── catpp_freestanding.c       # VGA, serial, memory cho kernel
│
├── kernel/
│   ├── main.c                     # Kernel entry (kmain)
│   ├── entry.s                    # Assembly boot (_start)
│   ├── linker.ld                  # Linker script
│   └── demo.cat                   # Code Cat++ demo
│
├── libc/                          # Minimal libc cho freestanding
│   ├── stdint.h
│   ├── stddef.h
│   ├── stdarg.h
│   └── limits.h
│
└── build_felis.sh                 # Build script

3. Cú pháp low-level chỉ có trong Felis OS

Bit operations

paw a = 0xFF & 0x0F       # AND → 15
paw b = 5 | 2             # OR → 7
paw c = 5 ^ 3             # XOR → 6
paw d = ~0                # NOT → -1
paw e = 1 << 4            # SHL → 16
paw f = 256 >> 4          # SHR → 16

Cast sang pointer

paw vga = cast(ptr, 0xB8000)
# Địa chỉ VGA text mode. 80x25 ký tự, mỗi ký tự 2 byte:
# byte 1 = ký tự, byte 2 = màu

Struct C-layout

struct Color
    r: u8
    g: u8
    b: u8
    a: u8

paw red = Color(255, 0, 0, 255)
meow sizeof(Color)   # 8

Volatile cho MMIO

volatile paw status = 0
# Compiler sẽ không tối ưu hóa biến này

Inline assembly

asm("cli")   # Tắt interrupt
asm("sti")   # Bật interrupt
asm("hlt")   # Dừng CPU
asm("nop")   # Không làm gì

4. Viết kernel code

Ví dụ 1: In "Hello"

meow "Hello from Felis OS!"

Ví dụ 2: Vòng lặp

paw i = 0
knead i < 10
    meow i
    i++

Ví dụ 3: Hàm

purr fib(n)
    sniff n <= 1
        give n
    give fib(n - 1) + fib(n - 2)

meow fib(10)

5. Build script

bash build_felis.sh

Các bước build:

  1. Transpile demo.cat → demo.c
  2. Compile entry.s → entry.o (assembly)
  3. Compile runtime → rt.o (VGA, serial)
  4. Compile main.c → main.o
  5. Compile demo.c → demo.o
  6. Link tất cả → felis.elf

6. Chạy trên QEMU

Cách 1 — Terminal (không cửa sổ)

qemu-system-x86_64 \
    -kernel kernel/felis.elf \
    -m 128M \
    -display none \
    -serial stdio

Cách 2 — Cửa sổ đồ họa

qemu-system-x86_64 -kernel kernel/felis.elf -m 128M

Cách 3 — Tạo ISO bootable

# Cần grub2-tools
mkdir -p iso/boot/grub
cp kernel/felis.elf iso/boot/
cat > iso/boot/grub/grub.cfg << 'GRUB'
menuentry "Felis OS" {
    multiboot /boot/felis.elf
    boot
}
GRUB
grub2-mkrescue -o felis.iso iso
qemu-system-x86_64 -cdrom felis.iso

7. Runtime freestanding

VGA text mode

VGA buffer ở địa chỉ 0xB8000. 80 cột × 25 hàng. Mỗi ký tự 2 byte:

  • Byte 0: ký tự ASCII
  • Byte 1: màu (4 bit nền + 4 bit chữ)

Bảng màu:

0 = đen      4 = đỏ đậm    8 = xám đậm     12 = đỏ nhạt
1 = xanh dương đậm   5 = tím đậm     9 = xanh dương nhạt  13 = hồng
2 = xanh lá đậm      6 = nâu        10 = xanh lá nhạt    14 = vàng
3 = xanh lơ đậm      7 = xám nhạt   11 = xanh lơ nhạt    15 = trắng

Serial port (COM1)

Ghi ra cổng 0x3F8. QEMU với -serial stdio sẽ hiện ra terminal. Dùng để debug kernel.

Memory

Bump allocator: cấp phát tuyến tính từ 0x100000 (1MB) đến 0x400000 (4MB). Chưa có free thật.

8. Giới hạn hiện tại

  • Không có keyboard input
  • Không có filesystem
  • Không có process
  • Không có heap allocator thật
  • Chỉ 1 CPU
  • Chưa hỗ trợ 64-bit
  • Subset Cat++: meow, paw, sniff, knead, purr, give, struct, cast

9. Hướng phát triển

Bước 1 — Keyboard driver

Đọc từ port 0x60. Cài IRQ1. Dịch mã scancode thành ASCII.

Bước 2 — Timer interrupt

Cài PIT (Programmable Interval Timer) ở 100 Hz. Dùng cho scheduler.

Bước 3 — Heap allocator

Thay bump allocator bằng free list. Cần quản lý block.

Bước 4 — Shell

Prompt cat> + đọc từ keyboard + parse + run Cat++.

Bước 5 — Filesystem

Cài FAT16 hoặc FAT32. Cần driver đọc/ghi sector từ disk.

10. Debug

Xem serial output

qemu-system-x86_64 -kernel kernel/felis.elf -serial stdio

Disassemble kernel

objdump -d kernel/felis.elf

Xem ELF info

readelf -h kernel/felis.elf
readelf -S kernel/felis.elf

Kiểm tra Multiboot

grub-file --is-x86-multiboot kernel/felis.elf

11. Ví dụ: vẽ chữ lên VGA

struct VgaChar
    ch: u8
    color: u8

paw VGA = cast(ptr, 0xB8000)

purr putc(row, col, ch, color)
    paw index = row * 80 + col
    # *(VGA + index*2) = ch | (color << 8)

putc(0, 0, 72, 0x0F)    # 'H' trắng trên đen
putc(0, 1, 101, 0x0F)   # 'e'
putc(0, 2, 108, 0x0F)   # 'l'
putc(0, 3, 108, 0x0F)   # 'l'
putc(0, 4, 111, 0x0F)   # 'o'
