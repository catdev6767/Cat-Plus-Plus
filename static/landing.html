Cat++ là gì?

Cat++ là ngôn ngữ lập trình nhỏ, chạy hoàn toàn trong browser. Cú pháp dùng từ khóa tiếng mèo — dễ nhớ, vui vẻ, phù hợp cho người mới học lập trình. Có thể transpile sang C để viết kernel OS (Felis OS).

Ví dụ

# Hello world
meow "Hello, Cat++!"

# Hàm với default param
purr greet(name, greeting = "Hello")
    give greeting + ", " + name

meow greet("Tom")          # Hello, Tom

# Class với operator overload
cat Vec2
    paw x
    paw y
    purr new(x, y)
        me.x = x
        me.y = y
    purr add(o)
        give Vec2(me.x + o.x, me.y + o.y)

paw c = Vec2(1, 2) + Vec2(3, 4)

Hiệu suất — Nhanh gần C++

Cat++ có 4 engine. Bạn chọn tốc độ hay linh hoạt tùy nhu cầu. Với ⚡ C native, code có type annotation được biên dịch sang C thuần (int32_t, double) — gcc -O2 tối ưu như C++ thật.

Benchmark — loop 1 triệu lần

purr sum_to(n: i32) -> i64
    paw total: i64 = 0
    paw i: i32 = 1
    knead i <= n
        total = total + i
        i = i + 1
    give total

Khi nào dùng gì?

  • ⚡ C native — code số học nặng, thuật toán (cần type annotation)
  • C boxed — code có list/dict/class phức tạp (chạy mọi code)
  • Interpreter/VM — prototyping nhanh, không cần type

Cài trên máy

# Yêu cầu: Python 3.8+
git clone https://github.com/catpp/catpp.git
cd catpp
python3 catpp.py

# Mở: http://localhost:5000

Docker

docker build -t catpp:1.0 .
docker run -p 5000:5000 catpp:1.0

CLI

python3 catpp.py repl              # REPL
python3 catpp.py run hello.cat     # Chạy file
python3 catpp.py fmt hello.cat -w  # Format
python3 catpp.py lint hello.cat    # Kiểm tra
