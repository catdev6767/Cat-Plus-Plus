hello.cat — Cat++ v3 
// Cat++ v3 — C++-like syntax, cat keywords
cat Point {
    paw int x;
    paw int y;

    purr Point(int a, int b) {
        me.x = a;
        me.y = b;
    }

    purr int sum() {
        give me.x + me.y;
    }
};

purr int main() {
    paw Point p = Point(3, 4);
    meow(p.sum());  // 7
    give 0;
}

Built seriously, named silly.

Cat++ v3 is a real programming language with cat-themed keywords. LLVM backend, classes, pointers, arrays, and a browser IDE.

⚡

LLVM native

Compiles directly to native binary via LLVM. No gcc, no C transpilation. ~2× slower than C, 1000× faster than interpreter.

🎯

C++-like syntax

Curly braces, semicolons, line comments. Classes, inheritance, pointers, arrays, structs, enums.

🐱

Cat keywords

meow print · paw var · purr func · give return · sniff if · swat else

🌐

Browser IDE

Run Cat++ in your browser via Pyodide. No install. Powered by Monaco editor, syntax highlight for v2 + v3.

📦

Multi-engine

Interpreter (dev), bytecode VM (medium), PyCompiler (fast), LLVM native (fastest). Pick per task.

🛠️

Real stdlib

File I/O, math, strings, crypto, HTTP, SQLite. sqrt, pow, read_file, upper, substr, and more.
