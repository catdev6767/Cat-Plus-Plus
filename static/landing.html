// Cat++ v3 — C++-like syntax, cat keywords
purr int main() {
    meow("Hello, v3!");
    give 0;
}

// Classes + inheritance
cat Point {
    paw int x;
    paw int y;

    purr Point(int a, int b) {
        me.x = a;
        me.y = b;
    }

    purr int sum() {
        give me.x + me.y;
    }
};

purr int main() {
    paw Point p = Point(3, 4);
    meow(p.sum());  // 7
    give 0;
}

Built seriously, named silly.

Cat++ v3 is a real programming language with cat-themed keywords — LLVM backend, classes, pointers, and a browser IDE.

⚡

LLVM native

Compiles directly to native binary via LLVM. No gcc, no C transpilation. ~2× slower than C, 1000× faster than interpreter.

🎯

C++-like syntax

Curly braces, semicolons, line comments. Classes, inheritance, pointers, arrays, structs, enums.

🐱

Cat keywords

meow = print, paw = var, purr = func, give = return, sniff = if.

🌐

Browser IDE

Run Cat++ in your browser via Pyodide. No install needed. Powered by Monaco editor.

📦

Multi-engine

4 engines to choose from: interpreter (dev), VM (medium), PyCompiler (fast), LLVM native (fastest).

🛠️

Full stdlib

File I/O, math, strings, crypto, HTTP, SQLite. read_file, sqrt, upper, substr, and more.

📦 Install locally

# Clone repo
git clone https://github.com/catdev6767/Cat-Plus-Plus
cd Cat-Plus-Plus

# Run Cat++ v3
catpp run hello.cat          # v2 syntax
python3 interpreter_v3.py hello.cat  # v3 syntax

# Compile native via LLVM
python3 codegen_llvm_v3.py hello.cat --build hello
./hello
